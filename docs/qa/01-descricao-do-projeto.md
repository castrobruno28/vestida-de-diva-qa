Projeto de QA — Vestida de Diva

1. Descrição do projeto

O Vestida de Diva é um protótipo de loja virtual de moda feminina desenvolvido para apresentar produtos, permitir a seleção de opções e simular o fluxo de compra.

2. Objetivo dos testes

Verificar se as principais funcionalidades do site operam conforme o comportamento esperado, identificar possíveis falhas e documentar os resultados dos testes manuais.

3. Escopo inicial

- Página inicial e identidade visual.
- Catálogo de produtos.
- Busca, filtros e ordenação.
- Detalhes dos produtos.
- Seleção de tamanhos e cores.
- Carrinho de compras.
- Formulário de checkout demonstrativo.

4. Limitações conhecidas

O protótipo não possui pagamento real. A disponibilidade de estoque, as cores e os tamanhos dependem das informações confirmadas pela loja.

5. Tipo de teste

Teste funcional manual, com registro dos resultados e evidências.

6. Status do projeto

Documentação inicial em preparação. A execução formal dos casos de teste será registrada individualmente nas próximas etapas.
