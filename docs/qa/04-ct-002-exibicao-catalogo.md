CT-002 — Exibição do Catálogo de Produtos

ID: CT-002

Funcionalidade: Catálogo de produtos

Objetivo: Verificar se os produtos cadastrados são exibidos corretamente no catálogo da loja.

Pré-condições:
- O site Vestida de Diva está disponível para teste.
- A página inicial foi carregada no navegador.

Passos:
1. Acessar a seção de produtos da loja.
2. Observar os produtos apresentados no catálogo.
3. Verificar se as imagens, os nomes e os preços estão visíveis.
4. Conferir se a apresentação dos produtos está adequada.

Resultado esperado:
Os produtos devem ser exibidos com suas imagens, nomes e preços correspondentes, sem elementos visuais quebrados.

Resultado obtido:
O catálogo foi exibido conforme verificado durante a execução do teste.

Status: Aprovado.
