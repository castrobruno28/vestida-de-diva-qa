CT-005 — Ordenação de Produtos

ID: CT-005

Funcionalidade: Ordenação do catálogo

Objetivo: Verificar se a ordenação altera a sequência dos produtos conforme a opção selecionada.

Pré-condições:
- O site Vestida de Diva está disponível para teste.
- O catálogo possui produtos cadastrados.
- As opções de ordenação estão disponíveis.

Passos:
1. Acessar o catálogo de produtos.
2. Localizar a opção de ordenação.
3. Selecionar a ordenação por menor preço, se disponível.
4. Observar a sequência dos produtos apresentados.
5. Conferir se os preços seguem a ordem selecionada.

Resultado esperado:
Os produtos devem ser apresentados na ordem correspondente à opção selecionada.

Resultado obtido:
A ordenação dos produtos foi realizada e apresentou o comportamento esperado durante o teste.

Status: Aprovado.
