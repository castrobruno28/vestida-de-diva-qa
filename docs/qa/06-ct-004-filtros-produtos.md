CT-004 — Filtros de Produtos

ID: CT-004

Funcionalidade: Filtros do catálogo

Objetivo: Verificar se os filtros permitem visualizar produtos de acordo com a opção selecionada.

Pré-condições:
- O site Vestida de Diva está disponível para teste.
- O catálogo possui produtos cadastrados.
- Os filtros estão acessíveis.

Passos:
1. Acessar o catálogo de produtos.
2. Identificar os filtros disponíveis.
3. Selecionar uma opção de filtro.
4. Observar os produtos apresentados.
5. Verificar se os resultados correspondem ao filtro selecionado.

Resultado esperado:
O catálogo deve apresentar somente os produtos que correspondem ao critério selecionado, conforme o funcionamento previsto do filtro.

Resultado obtido:
O filtro foi aplicado e o catálogo apresentou o comportamento esperado durante o teste.

Status: Aprovado.
