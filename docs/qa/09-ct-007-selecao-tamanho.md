CT-007 — Seleção de Tamanho

ID: CT-007

Funcionalidade: Seleção de tamanho do produto

Objetivo: Verificar se a cliente consegue selecionar um tamanho disponível antes de adicionar o produto ao carrinho.

Pré-condições:
- O site Vestida de Diva está disponível para teste.
- O catálogo de produtos está acessível.
- Existe um produto com opções de tamanho para selecionar.

Passos:
1. Acessar o catálogo.
2. Abrir um produto com opções de tamanho.
3. Identificar os tamanhos apresentados.
4. Selecionar um tamanho disponível.
5. Verificar se a seleção fica visível na tela.

Resultado esperado:
O site deve permitir selecionar um dos tamanhos apresentados e indicar claramente qual opção foi selecionada.

Resultado obtido:
A seleção de tamanho foi realizada e apresentou o comportamento esperado durante o teste.

Status: Aprovado.
