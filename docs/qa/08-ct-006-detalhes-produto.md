CT-006 — Detalhes do Produto

ID: CT-006

Funcionalidade: Visualização dos detalhes do produto

Objetivo: Verificar se os detalhes apresentados correspondem ao produto selecionado no catálogo.

Pré-condições:
- O site Vestida de Diva está disponível para teste.
- O catálogo de produtos está acessível.

Passos:
1. Acessar o catálogo.
2. Selecionar um produto.
3. Abrir os detalhes desse produto.
4. Conferir o nome e o preço apresentados.
5. Verificar se as opções de tamanho e cor são exibidas, quando disponíveis.

Resultado esperado:
Os detalhes devem corresponder ao produto selecionado, apresentando as informações cadastradas e as opções disponíveis para consulta.

Resultado obtido:
Os detalhes do produto foram exibidos conforme o comportamento esperado durante o teste.

Status: Aprovado.

Evidência: Captura de tela dos detalhes do produto selecionado, identificada como `CT-006.png`.
