CT-001 — Carregamento da Página Inicial

ID: CT-001

Funcionalidade: Página inicial

Objetivo: Verificar se a página inicial do protótipo é carregada corretamente no navegador.

Pré-condições:

- O site Vestida de Diva está disponível para teste.
- O navegador está aberto e pronto para acessar a página inicial.

Passos:
1. Abrir o arquivo `index.html` no navegador.
2. Aguardar o carregamento da página.
3. Verificar a identidade visual.
4. Conferir a exibição dos textos e das imagens principais.

Resultado esperado:
A página inicial deve carregar com a identidade visual, os textos e as imagens principais exibidos corretamente.

Resultado obtido:
A página inicial foi carregada corretamente no navegador, conforme verificado durante a execução do teste.

Status: Aprovado.

Evidência: Captura de tela da página inicial após o carregamento, identificada como `CT-001.png`.
