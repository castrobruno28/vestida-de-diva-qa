CT-008 — Seleção de Cor

ID: CT-008

Funcionalidade: Seleção de cor do produto

Objetivo: Verificar se o site informa corretamente que as cores do produto precisam ser consultadas com a loja.

Pré-condições:
- O site Vestida de Diva está disponível para teste.
- O catálogo de produtos está acessível.
- Existe um produto com opções de cor para selecionar.

Passos:
1. Acessar o catálogo.
2. Abrir um produto que apresente a opção de cores.
3. Localizar a mensagem “Consultar cores disponíveis”.
4. Verificar se a mensagem está visível e compreensível.

Resultado esperado:
O site deve exibir a orientação para consultar as cores disponíveis, sem apresentar cores como confirmadas quando não há essa informação.

Resultado obtido:
A opção “Consultar cores disponíveis” foi exibida no campo de cor do produto.

Status: Aprovado.
