# Vestida de Diva — protótipo de e-commerce

Protótipo front-end demonstrativo de uma loja de moda feminina, criado para evolução de desenvolvimento web e prática de QA manual.

## Tecnologias
- HTML5
- CSS3 responsivo
- JavaScript puro
- Git/GitHub (para versionamento e portfólio)

## Funcionalidades
- Catálogo com sete produtos e preços informados nas publicações da loja
- Busca por nome, categoria e descrição
- Filtro por categoria e ordenação por preço/nome
- Detalhes de produto com seleção de tamanho e cor
- Carrinho com alteração de quantidade, remoção e subtotal
- Validação básica de nome e e-mail no checkout demonstrativo
- Layout adaptado para telas menores

## Como executar
1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador.
3. Não é necessário instalar dependências nem iniciar servidor.

## Importante
Este é um protótipo local. Os preços foram transcritos das capturas de publicações fornecidas. A disponibilidade de estoque e algumas opções de tamanho/cor ainda precisam ser confirmadas com a loja. Não há backend, estoque real, autenticação, integração de pagamento ou persistência de pedidos. O checkout é apenas demonstrativo; não informe dados reais de pagamento.
